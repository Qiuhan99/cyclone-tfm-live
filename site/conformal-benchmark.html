C1 AUDIT / SAME NAME DOES NOT MEAN SAME PIPELINE

C1 protocol audit

Loading the independent audit…

The original PI+ study has 60 next-6h endpoints from five storms; the current study has 169 fixed-24h endpoints from 27 storms. The original C1/Base matched-area ratio is 0.794 with an interval crossing 1. Its CHAMPI short replay never reached a second context refresh. These protocols cannot establish each other’s causal mechanism.

A sample rate above target does not establish systematic overcoverage. The reported 95% intervals describe uncertainty in coverage estimates, not cyclone position. Residual feedback must learn a useful error signal; improvement is empirical.

ACTUAL RUNS / NO PLACEHOLDER SCORES

Model versions & information budgets

Chronos and Moirai use the same 48h position history. The shared-CV branch removes the last 6h motion reference and adds it back after residual forecasting. Direct ENU outputs remain available. F0 is the position-feature reference; F2/C0/C1 add intensity, climatology and labelled historical contexts. Pretraining overlap with historical cyclones is unverified.

Native uncertainty vs conformal calibration

Every model centre receives the same causal conformal outer layer. Native per-coordinate 10–90% intervals are recorded separately; their two-dimensional rectangle has no automatic 80% joint guarantee. TimeGPT remains pending API access and has no score.

Representation sensitivity & study limits

Direct and CV-residual targets can change the ranking. In the earlier 6–72h joint-circle study, coverage improved from 81.9% for Base to 89.7% for C1, with larger regions. That result is retained as evidence for its own protocol, separate from the +24h ellipse and motion-stratum evaluations.

All studied years and CHAMPI have been inspected; this benchmark is exploratory. Whole-storm paired intervals are reported only for the primary comparisons. An unexposed season and known-shift processes are needed for confirmatory evaluation.
