THE RESEARCH QUESTION

研究问题：历史残差能否改善覆盖与区域效率？

在明确的漂移、上下文陈旧或信息受限条件下，先检验 TabPFN＋基础 conformal 的实际覆盖，再检验 [X、基础预测、已验证残差历史] 的二层学习。对原始残差与校正后创新使用相同的校准算法，同时报告覆盖与体积。

Rt = m(Xt, Ravailable) + εt→ Cbaset,α / Ccorrectedt,α
m为可学习的条件位置函数，R仍含随机创新。待验证的主张是条件性的。原生预测区间、基础 conformal 和自适应 conformal 分别评价；点误差作为机制诊断。

METHOD NOTE / v1
THE CENTRAL QUESTION

条件残差与校正模型

漂移、上下文陈旧或输入容量受限时，TabPFN 的误差可能仍与 X 及历史残差有关。我们学习这种可预测部分，再对校正后的创新流做联合 conformal 校准。

这里“残差是关于 x 的函数”精确指 m(x)=E[R | x]。观测残差 R 本身仍是随机变量；创新 ε 不会因为二次学习而自动消失。

CONDITIONAL MEAN DECOMPOSITION
Rt,h = mh(Xt, Ravailable) + εt,h
E[εt,h | Xt, Ravailable] = 0

可学习的结构 + 不可由同一信息集解释的创新

预测与区域构造流程

THE COMPLETE PIPELINE
01

TabPFN 基础预测

Xt → P̂baset,h

使用历史轨迹与起报安全特征，缓存严格样本外预测。

02

构造历史残差

Rj,h = LogP̂base(Pj+h)

只有真值已到达的残差可用，要求 j+h ≤ t；未来残差不是输入。

03

Residual + X → TabPFN

[Xt, Ravailable] → R̂t,h

二层 TabPFN 从历史 (X, R) 对学习。完整 X 的 C1-TabPFN 为新二层模型；C1-Ridge 与仅 X 的二层模型作为对照。

04

校正与重新校准

P̂corr = ExpP̂base(R̂)

在新中心重新计算球面创新，对全 H 步联合分数做秩校准。

CAUSAL TIMELINE

历史残差的可用时间

历史起报 j真值到达 j+h当前起报 t预测 t+h

训练对来自历史样本外预测。输入是当时可得的 X 与已验证残差；训练目标是之后观测到的 R。当前未知的 Rt,h 不能作为当前输入。

v2保留全部10维原始X，显式加入当前基础预测的东/北位移，并输入四组已验证残差、年龄与可用标记，共28维。C0仅用前12维；同信息集Ridge作对照。每时效使用最新320条已到达标签，每完成32条刷新，TabPFN输出中位数。v1的冻结14维单残差模型仍独立保留。并比较同信息集岭回归，以及只输入 X 的二层 TabPFN，分辨再次学习与历史残差的贡献。v1的TabPFN残差输出使用预测均值；v2使用中位数。旧六维 C2 与 E7 作为独立历史协议保留。

v1协议：基础模型只用 2016 年前可得标签，所有特征要求三个连续历史位置；2016 拟合校正器，2017 选择门控，2018 拟合几何，2019 校准分位数，之后固定规则测试。历史年份已在先前研究中被查看，结果仍标记为探索性；门控不保证未来无害。

TWO COMPLEMENTARY CHANNELS

点预测改善与尾部误差

Residual feedback学习条件位置 → 改变创新流
Conformal calibration校准联合分数 → 调整集合阈值

均值校正无法单独解决所有尺度漂移；MSE 变好也不推出 conformal 区域变小。效率比较必须同时报告实际覆盖与集合大小。

JOINT SCORE / MAXSCORE

整轨迹联合分数

St = maxh≤H √(Ut,hᵀ Σh⁻¹ Ut,h)

有限样本秩 k=⌈(n+1)(1−α)⌉。校准整条轨迹的最大分数，目标是 ALLh 同时覆盖。只有校准与测试单元可交换时，标准秩论证才给出精确的边际联合覆盖保证。

JOINT GEOMETRY / MAHALANOBIS

跨时效协方差

St = √(Utᵀ Ω⁻¹ Ut), Ut ∈ ℝ2H

地图使用联合椭球的边缘协方差块 Ωhh 生成投影，不能用条件协方差块代替。所有投影内的逐点真值均被覆盖，仍不足以判定整条轨迹在全维椭球内；联合事件按全维分数判断。

INTERPRETATION

陈旧基础预测与最新基础预测

12h 中，校正相对陈旧 Base 的改善从 k=0 的约 5.9% 增长到 k=8 的约 34.4%。但 k=8 校正后 MAE 仍约 334 km，高于新鲜 Base 的约 85 km。

这支持“陈旧上下文留下可预测误差”的解释，也保留其部署边界：现有台风结果不支持主动降低基础模型新鲜度来换取更好预测。

PROOF AUDIT

统计定义与限制

  1. R 是随机变量，m(x)=E[R|x] 才是条件均值函数。
  2. MSE 下降不推出 90% 分位数或区域体积下降。
  3. 可交换的依赖本身不破坏秩对称性；漂移与非交换结构需另行评估。

旧理论台账的混合尺度命题含过强的单调性表述，仍需收紧条件；本网站不将其提升为新定理。
