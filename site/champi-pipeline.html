02 / TRACK CHARACTERISTICS

CHAMPI为什么适合检验这个思想？

短序列，带运动变化

每次使用最近9个连续6h定位点，覆盖48h。经纬度、速度、转向和加速度提供运动结构；快速转向也可能令历史残差迅速失效，不能预设校正必然获益。

位置与强度异质

经度使用相对起报点的环绕差和正余弦编码；位置运算在球面切平面完成。风速与气压缺测分别附可用标记，零填充不被解释为真实零风速或零气压。

观测会修订

当前下载前缀可真实用于新预测；重建过去残差使用的是当前可见修订资料。单行历史真实发布时间未知，因此不将重建结果宣传为严格历史业务回放。

04 / ACTUAL MODEL INFERENCE

Base、C0与C1怎样预测？

  1. 冻结基础模型，用历史上下文推理

    本地TabPFN-3.5检查点，CPU、随机种子42、1个估计器，输出中位数。固定1020条历史上下文，涵盖761场历史风暴，按5个时效分层各204条；不是完全无历史标签，也没有在CHAMPI上重新预训练。

  2. 先建立等速度参考，再学运动偏差

    用最近6h运动在球面外推；TabPFN学习历史真实位移与等速度位移之间的偏差。将预测偏差加回参考位移，再由球面Exp映射得到经纬度。时效为6/12/24/48/72h，网站重点看24h。

    d̂Base(t,h) = dCV(t,h) + fF2(Xt,h)
  3. C0控制额外模型层，C1检验残差信息

    二层校正器使用固定2016年最近320条已完成历史样本。C0输入52维F2加2维Base位移，共54维；C1额外输入最近4个同场、同lead已成熟残差的东／北分量、年龄与可用标记，共70维。残差经大圆平行移动对齐当前起报切平面；缺失补0并标记，最多保留96h成熟年龄。

    rt,h = Logpt(Yt+h) − d̂Base(t,h)
    d̂C1(t,h) = d̂Base(t,h) + g(Xt,h, d̂Base, Rpast)

    只使用过去起报且valid time ≤ 当前起报的残差。新标签用于输入和校准更新；当前C1拟合上下文仍固定，未启用按CHAMPI重训或门控。C1/C0比较才隔离残差历史增量。

  4. 用已成熟误差校准位置集合

    2019误差预热，滚动取最近100条可用分数，秩为ceil((n+1)(1−α))。24h边际只等待24h标签成熟；五时效联合MaxScore等待整条72h标签成熟。80/90/95%分别保存，阈值发报时冻结。

    当前实时输出是球面位置圆；历史研究保留真实椭圆实验，两者不混用。Conformal依赖可用校准分数，不是基础模型在无任何校准样本时自动提供覆盖保证；时间依赖和漂移下当前结果是经验校准。

05 / MAC → GITHUB → MAP

如何自动同步到网站？

公开源检查 → 输入与版本检查 → 本地真实推理／复用同版本 → C0/C1与Conformal → 两个公开JSON → GitHub Actions → 地图

Mac登录后的后台任务按15分钟间隔检查，上一轮结束后再等待；没有新B-deck内容时保留模型原生成时间。出现新定位或修订数据时重新推理。仅发布路径、区域、来源和时间等公开结果；模型权重、原始历史数组与私钥留在本机。

模型数据分支只含两个公开JSON及与main一致的公开工作流；更新通知main分支受保护的部署工作流，完成后地图每60秒读取；从下载到公网可见还包含推理、网络、排队与部署时间。官方资料另有每小时第7/37分钟的计划检查。Mac睡眠、关机、退出登录或断网会影响本地更新；公网保留上次成功版本并按时间显示过期。

上传采用普通非强制推送并检查新旧版本；云端与Mac并发时分别保留较新官方资料和较新模型。上传成功不等于已经部署，公开网页中的实际版本时间是最终核验依据。
