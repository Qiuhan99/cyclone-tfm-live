# 公开版的运行方式

本网站由Qiuhan99维护，原CYCLONE界面与研究数值保持。网站和数据更新任务是独立服务。

官方资料、外部模式路径由后台定时检查；页面每分钟读取已经发布的缓存。计划任务可能延迟，官方源也可能停止更新；页面显示各自原时间、来源失败和过期状态。

TabPFN预测来自独立私有推理环境。这里不分发模型权重、原始训练/校准样本、完整科研代码或私人对话。新的官方资料不会改变旧TabPFN预测的起报或实际生成时间。推理服务停机时，模型路径会逐渐过期，不能将旧缓存称为最新推理。

24h圆/椭圆区及其余研究表是锁定资料上的研究回放，与实时区分开。后验同覆盖面积匹配只用于诊断，不改写实际发报阈值。真实数据及负结果均保留。

当前版本仅适配CHAMPI，不宣称支持全球自动活跃台风发现。未来强度仅展示外部模式真实字段，官方预警直接标注来源，不由模型位置区域推算。

代码与部署说明：[Qiuhan99/cyclone-tfm-live](https://github.com/Qiuhan99/cyclone-tfm-live)。链接是目标仓库；上线状态以GitHub实际返回为准。
