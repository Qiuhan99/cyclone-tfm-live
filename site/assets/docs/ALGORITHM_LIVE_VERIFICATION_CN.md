# 本研究算法实时窗口与前瞻核验协议

本窗口：`algorithm-live.html`。研究路线是 Tabular Foundation Model → 残差校正 → Conformal 位置预测。它独立于官方风力、风级和预警报道，但使用相同公开实况接受检验。原网站、历史案例、消融、圆/椭圆实验及负结果均保留。

## 1. 三条算法路径

- **Base / TabPFN CV-F2**：最近48小时9个定位点形成F2的52维特征，预测相对6小时匀速基线的东西/南北位移残差，再还原为球面位置。TabPFN-3.5固定权重、历史上下文与既定推理配置保持不变。
- **C0**：基于F2和Base输出估计预测残差，检验额外校正模型的作用。
- **C1**：在C0信息基础上加入最近4个同台风、同lead且目标时刻已到达的残差及年龄/可用标记。新实况更新输入和校准队列；不代表重新训练基础模型。

Base→C1 的中心移动量不是误差减少量。C1需同时与Base和C0比较，才能区分额外校正模型和残差历史通道的作用。默认24h，保留6/12/48/72h，全部读取真实保存的预测点。

## 2. Conformal显示

逐时效边际80/90/95%位置区域的半径，直接来自真实推理输出的 `radius_<level>_km`；地图用球面指数映射绘制边界，面积使用

`A = 4πR² sin²(r / (2R))`，`R = 6371.0088 km`。

这不是整条轨迹同时覆盖的区域。当前实时接口只输出圆；历史已发椭圆及同覆盖面积实验仍在原研究页面，没有把历史椭圆参数移植为新起报结果。实时椭圆需要独立冻结几何、因果校准和前瞻检验后接入。名义覆盖率不是已实现的经验覆盖率；时序依赖和漂移下不宣称无条件的严格有限样本保证。

## 3. 官方路径与外部模式

CMA数据来自中央气象台公开地图同一接口：

- 身份列表：https://typhoon.nmc.cn/weatherservice/typhoon/jsons/list_2026
- CHAMPI详情：https://typhoon.nmc.cn/weatherservice/typhoon/jsons/view_3359119

运行时通过英文名CHAMPI与编号2630解析身份，再读取详情；不固定猜测其他风暴ID。安全解析JSONP而不执行JavaScript。只将机构码BABJ标为CMA，核对UTC字符串与epoch、机构、lead和经纬度。原始单行首次业务发布时间未知；当前接口返回的旧预报不能用于宣称当时已获得。

CMC、UKM、NGX来自UCAR A-deck，属于外部数值模式；不将其冒充官方机构路径。官方预报没有某个lead时保持缺失，不从较短预报外推24h。地图默认同一起报，两图保持同一范围；切到“各来源最新”仅用于态势展示。即使同一起报，业务发布时间、观测分析与信息条件仍不同，不能等同受控算法试验。

## 4. 先封存，再等真值

公开 `champi-operations.json` 内的 `verification` 保存逐点版本及首见真值，Git `live-data` 分支历史也保留快照。模型、原始训练样本与密钥不公开。

1. 上传新预测时，将未来目标记录为pending。预测快照ID由风暴、模型、起报、lead、有效时刻、位置和已发Conformal半径的规范JSON计算SHA256。
2. 后续发布进程从已经存在的公开Git提交读取该记录，才写入确认时间。只有 **公开确认时间严格早于有效时刻** 的记录有资格接受前瞻检验。确认过晚永久排除。该时间保守晚于实际首次上传时间；不声称精确的业务发布时延。
3. 目标到达后，采用随后首次取得的UCAR工作B-deck定位点，保存其首见时间和来源哈希。后续最佳路径修订不覆盖该检验真值。真值是操作性验证参考，不能视为无测量误差的绝对真实中心。
4. 配对键严格为 **storm + issue + lead + valid**，不匹配最近时刻、不插值、不将不同起报预测强行比较。相同键的修订版本均保留，但排名只用最早封存且合格的版本。
5. 每对模型在各自共同样本上计算球面终点距离的均值（MAE）、胜出次数，以及本研究所选水平的经验覆盖和平均球面面积。不同对照行的样本集合可能不同，不做跨行无条件排行榜。没有对应机构Conformal区域，不比较未经统一覆盖协议的原生概率圈面积。
6. `n=0` 显示待实况及缺失指标，不能显示零误差或100%覆盖。旧历史预测不补记为前瞻业务成绩。当前风暴的少量、重叠起报结果不能证明普遍优越性。

确认基于公开Git数据分支，不等于Pages已经完成部署；窗口另显模型/核验版本时间。Mac睡眠、网络失败、源站停报或GitHub部署延迟时保留旧版本并显示时间，不伪造新起报。
