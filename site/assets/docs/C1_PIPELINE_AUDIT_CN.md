## 样本覆盖比例不等于长期真实覆盖概率

## 理论上C1为什么不是无条件必胜

以下先讨论当前训练目标所在的固定ENU切平面平方损失，不将它直接等同于球面MAE或Conformal面积。令基础误差e=Y−μ，学到的修正为a，修正后误差e′=e−a。逐步展开：

1. ||e−a||² = (e−a)ᵀ(e−a)。
2. = eᵀe − 2eᵀa + aᵀa。
3. 因此修正后减修正前的平方损失为 ||a||² − 2eᵀa。
4. 只有2eᵀa > ||a||²时该次修正才改善；方向错误或幅度过大都会使损失增加。

如果a是测试分布下的oracle条件均值m(H)=E[e|H]，则E[(e−m)ᵀm]=0，所以 E||e−m||²=E||e||²−E||m||²，不增加总体平方风险。若用估计值a_hat(H)，条件正交又给出：

E||e−a_hat||² = E||e−m||² + E||a_hat−m||²。

与基础风险相比，只有估计误差E||a_hat−m||²小于可预测信号E||m||²时才有改善。额外残差信息可降低oracle最优风险，但不保证有限上下文估计器实现该最优值。当前模型还使用逐坐标中位数，评价包含球面MAE、覆盖和面积，不能直接套用条件均值平方风险定理。冻结2016上下文也不保证在漂移后的2024/CHAMPI仍估计相同的条件规律。

## Conformal为什么可能高于目标

标准split-Conformal在相应交换性等条件下给出边际覆盖下界；连续分数且相应条件成立时，上界通常为1−α+1/(n_cal+1)。这是对校准集与新样本随机性取平均后的覆盖概率界，不是任意有限测试队列必须恰好覆盖90%的断言。滚动几何、时间依赖和分布漂移下，标准交换性论证不能直接套用当前分支。

PI+/ACI一类反馈控制与普通rolling rank不是同一个算法。分布漂移下的长期频率结果有明确算法与条件，不能直接推导出每个短窗口、每个运动子集都不高于90%；也不直接保证更小区域。原PI+本身保留保守组件，不应被宣传为绝无过覆盖。

## 一个说明“点误差更好不等于区域必然更小”的反例

设一维基础误差以0.95概率为0、以0.05概率为100。均值修正a=5将平方风险从500降到475；但绝对误差的90%分位数从0变成5。若区域始终以各自点预测为中心并对绝对误差校准，修正后的区域反而更宽。这不是台风数据的模拟结果，只是说明两个评价目标没有无条件单调关系的数学反例。分数有原子/并列也说明标准连续分数上界不能直接套用；样本覆盖高于目标本身不等于算法失效。

补充限定：原代码支持每32步刷新残差上下文，但原CHAMPI短回放的k=1实际只有一次拟合，每坐标首批7条上下文，未达到第二次刷新。因此“存在刷新机制差异”不是本次效果差异的已验证原因；短回放也无法验证原控制器的长期适应性质。需在相同队列和目标上单独做组件消融，才能归因。
