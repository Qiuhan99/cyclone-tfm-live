# SPCI 台风案例对照

本页来自已经完成的滚动v2历史预测缓存。选择此前确定的GAEMI、AMPIL、DORA、TALIM，纳入其全部44个起报点；未按新增对照结果重新筛选风暴。

任务为24h预报的四个二维位置，联合维数8。Base、C0和C1的路径保持不变，仅接入相同规则的序贯条件分位数校准。SPCI为坐标矩形适配：每坐标使用α/8，报告八个坐标同时命中的联合事件。原方法见[SPCI论文](https://proceedings.mlr.press/v202/xu23r.html)。

每次发报只使用该时刻已经完成24h标签的历史样本，训练窗口320。残差滞后只来自同一风暴，最多四个；历史不足使用零填充与可用标记，不拼接不同风暴。QRF使用10棵树、深度2、五点beta网格、固定随机种子42，每次发报重新拟合。分位数后端为quantile-forest，与作者sklearn_quantile的数值不保证一致。

因此本轮是**固定预测缓存上的SPCI适配对照**，不是作者完整bootstrap/LOO基础预测层的逐值复现，也不是强气象预测器新实验。

## 如何读网站结果

实际发布阈值下，Base＋SPCI覆盖38/44，C1＋SPCI覆盖37/44。两者名义水平均为90%，但实际覆盖未达到90%。

后验匹配将双方经验覆盖统一到40/44，即90.91%，此时C1/Base几何平均8维体积比为0.760132；相对C0的比值为0.569328。这些是事后精选案例上的描述性结果，不作总体推广或显著性结论。匹配阈值不用于地图、实时预测或校准训练。

SPCI矩形的匹配方式为：以已发布区间的中点为中心，将每个坐标半宽共同乘以c；取逐起报点标准化最大偏差的第ceil(0.9×44)=40个顺序统计量作为c。体积随c的八次方变化。比较量为exp(mean(log V_C1−log V_Base))。

图中SPCI与MaxScore各自将Base归一化为1，不能按两个比值对区域族的绝对大小排名。路径回放继续使用其标明的实际发布区域，未替换为后验匹配区域。
