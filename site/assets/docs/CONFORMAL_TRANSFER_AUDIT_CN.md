# Conformal 校准对象、台风数值复算与 ETTh1 迁移审计

审计版本：`conformal_transfer_audit_v1`。日期：2026-10-27。

结论：截图中的主指标可以由原始区域记录独立重算；未发现覆盖率、面积和匹配面积比的汇总计算错误。页面确有首次加载漏画残差反馈曲线、模型颜色重复、坐标范围过宽和比较参照不清的问题，本次修复展示。当前台风实验与 ETTh1 强结果的模型更新、漂移构造、校准规则和评价对象不同，不能把 ETTh1 的幅度直接当作台风实验应达到的数值。本次没有更改算法、模型预测、校准阈值或原始实验结果。

## 1. 从输入到最终预测：区分两种“残差”

每个起报时刻 t、预测时效 h，设当前台风位置为 p_t，未来真实中心为 Y_(t+h)。在起报点的球面切平面上，真实二维位移（东西、南北，km）为：

\[
u_{t,h}=\operatorname{Log}_{p_t}(Y_{t+h})\in\mathbb R^2.
\]

第一阶段接收起报时已可得的表格特征 X，52 维 F2 特征；冻结的 TabPFN 权重利用既有带标签历史上下文进行推理，直接预测未来位移：

\[
v_{t,h}=\widehat f(X_{t,h}),\qquad r_{t,h}=u_{t,h}-v_{t,h}.
\]

这里 **r 是第二阶段需要学习预测的残差向量**。H 由已成熟、同台风、同时效的历史残差向量，以及年龄和可用性掩码组成。四个槽位各含两个向量分量、一个年龄、一个掩码，共16维；不同起报点的向量须先平行移动到当前起报切平面。修正器输入为 [X,H]，共68维；没有拼接 Base 输出，没有 CV 位移参考项，也没有缩放或混合修正量。

\[
\delta_{t,h}=\widehat g(X_{t,h},H_{t,h}),\qquad
v^{RF}_{t,h}=v_{t,h}+\delta_{t,h}.
\]

再映回球面得到两种完整的中心位置预测：

\[
\mu^{B}_{t,h}=\operatorname{Exp}_{p_t}(v_{t,h}),\qquad
\mu^{RF}_{t,h}=\operatorname{Exp}_{p_t}(v_{t,h}+\delta_{t,h}).
\]

**Conformal 校准针对最终预测的误差；主方法校准 RF 的误差流，Base 的误差流独立校准作为对照。** 在真实中心到达后，分别计算：

\[
e^{B}_{t,h}=\operatorname{Log}_{\mu^{B}_{t,h}}(Y_{t+h}),\qquad
e^{RF}_{t,h}=\operatorname{Log}_{\mu^{RF}_{t,h}}(Y_{t+h}).
\]

这里 **e 是用于 conformal 的最终预测误差**。在平直空间近似中，e^B≈r，e^RF≈r−δ；球面代码实际从各自最终预测中心计算 Log，因此并不直接把起报切平面的 r−δ 当作最终中心切平面的向量。

得到的集合预测对象是 **未来真实台风中心 Y**，不是 H，不是 g 的参数置信区间，也不是校准 TabPFN 原生分位数。当前截图评价单个 h 对应的二维终点；其90%覆盖不是整条6–72h路径同时90%覆盖。

## 2. 圆形与椭圆如何校准

每个方法、每个时效分别维护自己的历史误差与分数，不共用 Base 的误差阈值。

### 圆形

分数为球面距离：s_i=‖e_i‖（km）。当前终点区域为：

\[
C^m_{t,h}=\{\operatorname{Exp}_{\mu^m_{t,h}}(z):\|z\|\le q^m_{t,h}\}.
\]

圆形的协方差在统一代码中设为单位阵，q 的单位是 km。半径 q 的球面圆帽面积为 4πR²sin²(q/(2R))，不是无限平面上的近似 πq²。

### 椭圆

将过去已成熟的、位于各自预测中心切平面的误差平行移动到当前预测中心切平面。取最近最多128个几何误差，计算中心化样本协方差 S，并采用当前锁定的收缩：

\[
\Sigma=0.9S+0.1\frac{\operatorname{tr}(S)}2I,
\]

另设最小特征值1e−6 km²。样本均值仅用于估计协方差，**没有把椭圆中心额外平移为残差均值**。

每个历史预测的分数都使用它自己起报时冻结的几何：

\[
s_i=\sqrt{(e_i)^\top(\Sigma_i)^{-1}e_i}.
\]

这称为 prequential 分数。历史标签成熟后才可加入分数池，当前标签绝不参与本次阈值选择。最近最多256个已成熟分数排序；名义1−α覆盖的阈值为：

\[
k=\lceil(n+1)(1-\alpha)\rceil,\qquad q=s_{(k)}.
\]

若 k>n，严格的有限样本规则给无穷阈值，不以最后一个有限分数冒充该分位数。最终区域为：

\[
C^m_{t,h}=\{\operatorname{Exp}_{\mu^m_{t,h}}(z):z^\top(\Sigma^m_{t,h})^{-1}z\le(q^m_{t,h})^2\}.
\]

切平面半轴长度为 q√λ1、q√λ2，方向由 Σ 的特征向量决定。小区域的面积近似为 πq²√detΣ；正式结果对球面 Exp 的 Jacobian 做积分。令 d(θ)=(cosθ,sinθ)，ρ(θ)=q/√(dᵀΣ⁻¹d)，独立审计使用：

\[
A=\int_0^{2\pi}R^2\left[1-\cos\left(\frac{\rho(\theta)}R\right)\right]d\theta.
\]

生产代码使用等价的 Cholesky 参数积分，审计另用物理极坐标的2048节点积分，两者数值相符。

截图中的 benchmark 使用上述128/256终点校准。实时地图另有各方法100个成熟距离分数的圆形校准，以及单独存储的多时效最大分数校准；它们的窗口和评价对象不能混用。

有限样本秩规则不意味着在任意漂移、时序相关下自动严格覆盖；它也不要求一个有限测试集的经验覆盖必须恰好为90%。

### “同覆盖”到底怎么算

它是事后诊断，不是当前起报能使用的阈值。每个方法计算所有测试终点的 a_i=s_i/q_i，再取第 ceil(N×0.9) 个次序统计量 a_(k)，统一设 q_i*=a_(k)q_i。对 N=169，至少153个终点被覆盖，经验覆盖153/169=90.5325%。重算各区域面积并取几何平均，最后算 RF/Base 比值。

这与“原始阈值下区域面积的算术平均”是两个统计量，不能用608138/634555去验证0.941。原表默认以 F0 position-only 为参照，卡片却以 F2 Base 为参照，也造成混淆；本次将默认参照统一为 F2 Base，仍允许切换 F0。

coverage 92.3→91.1 更接近90%目标，只代表该样本的绝对偏离缩小，不能单独证明抗漂移；它还相当于少覆盖两个终点。必须连同面积、样本相关性及区间阅读。

## 4. 为什么与 ETTh1 的强改善不一样

### 4.1 找到了强结果，但不是当前台风配置

本地 `results/realdata_verification_s0.json` 和 `src/realdata_verification.py` 的 ETTh1 剂量实验：7维序列，以更新间隔 k 控制 Base 的陈旧度，采用 **滚动 SCALAR-C** 残差预测（尾随512、每32步重拟合、系数限制[0,1]）和 L2（滚动秩 + ACI）校准；协方差为尾随300的 Ledoit–Wolf。这份强结果不是当前68维 [X,H] 的冻结上下文 TabPFN 修正器。指出这一差异不改变用户主算法，也不把 SCALAR-C 当作网站主方法。

令 l 为平均 log体积，跨维度比较的体积等效线性尺度比为 exp((l_RF−l_Base)/7)。

| ETTh1 陈旧度 | Base 覆盖 | 修正覆盖 | 归一化体积比 V^(1/7) | 注释 |
|---|---:|---:|---:|---|
| k=0，新鲜基座 | 89.2544% | 89.2544% | 0.995820 | 同覆盖下改善0.42%，本来就很小 |
| k=8 | 88.8158% | 89.0351% | 0.766301 | 陈旧度增加后有更强可预测误差 |
| k=32 | 90.1316% | 88.1579% | 0.690265 | 约31%尺度缩小，但覆盖降低1.9737 pp |

这里 n=456；源脚本的 conformal 统计从 residual_end+100 到 T，包含了最后200个标为warmup的时刻；点预测增益使用最后256个时刻。两项不能当作同一评测窗口。原中文摘要将覆盖写成“同覆盖约0.89”，不等于严格匹配后的90%；演讲时应使用上表的实际覆盖。

另一个早期 ETTh1 C1_OBS_LR 实验是 `results/etth1/conformal_results.csv`：Base覆盖87.50%，C1覆盖86.8421%；7维几何体积比0.757750，等效线性尺度比0.961146。它也不是“同90%覆盖下缩小24%”的证据。7维体积比和台风2维面积比需要区分；当前台风0.941291面积比对应等效线性尺度比√0.941291≈0.970202。维数会放大体积数字，但并不能解释受控深陈旧实验的全部差异。

### 4.2 台风实验的实际适应条件更弱

| 条件 | ETTh1 剂量实验 | 当前 direct-core 台风实验 |
|---|---|---|
| 漂移/失适应来源 | 人为控制 Base 更新间隔 | 自然发生的台风变化，没有同样的受控陈旧剂量轴 |
| 修正器 | 滚动 SCALAR-C，每32步更新 | TabPFN固定2016历史残差上下文；H随成熟标签变化 |
| 连续流 | 长连续小时序列 | 各台风较短；不同台风独立从2019预热状态开始 |
| 校准 | LW300 + 滚动秩/ACI，另有PI比较 | 收缩协方差128 + 分数池256，无ACI/PI |
| 输出集合 | 7维椭球/壳层体积 | 固定时效的2维球面终点区域 |

主实验每次起报的分数池平均206.13个，其中本台风仅3.13个，2019预热分数占比平均 **98.4951%**。这由保存的逐起报 trace 直接统计。因果更新并不等于旧校准分布已充分被当前分布替换；也不能把H滚动输入误解成 g 的带标签上下文已经滚动重建。

因此，一个合理的研究问题是：在保留 v=f(X)、r=u−v、v_RF=v+g(X,H) 的前提下，滚动上下文、标签成熟时延和校准窗口是否能迁移 ETTh1 的适应收益。**本次未擅自修改这些锁定条件**。后续若研究该问题，应使用新协议名，对冻结/因果滚动上下文做消融，在未查看的台风季验证，完整保留旧结果；不能通过改坐标或筛掉失败样本获得科研结论。

## 5. 理论上何时残差反馈会更好

在同一个起报切平面，设 r=u−v，δ=g(X,H)。逐样本的平方误差差值恰为：

\[
\|r\|^2-\|r-\delta\|^2=2r^\top\delta-\|\delta\|^2.
\]

因此向正确方向修正仍不够，修正幅度/估计噪声过大也会损失精度。若 m=E[r|X,H]，且 δ 是同一条件信息的函数，对条件期望展开可得：

\[
E\|r-\delta\|^2=E\|r\|^2-E\|m\|^2+E\|\delta-m\|^2.
\]

这是平方误差下的结论：可预测信号 E‖m‖² 大于修正器估计误差 E‖δ−m‖²，才获得总体收益。真实条件均值修正不会增加总体MSE，但有限上下文估计的 g 不自动满足该最优条件。该恒等式也不是球面MAE、90%尾部分位数或区域面积必然改善的证明。

原始点预测审计显示，台风+24h修正后只有70/169个终点的位置误差减小；当前 g 未稳定提取足够可迁移信号。这与“算法思想无效”是不同判断，也不能用它推断 ETTh1 的机制已经在台风上得到同样验证。

## 6. 本次展示修复与可复现边界

- 修复初始化顺序：先填充模型下拉框，再读取有效选项并画图。真实浏览器会将不存在的 option 值设为空，原测试中的普通对象没有模拟这一行为；因此过去可能显示RF选项，却只画Base两条曲线。
- 图中同时绘制 Base/RF × 冻结/因果滚动四条曲线；实线/虚线区分校准器，颜色区分模型。诊断固定+24h/90%/椭圆/全部起报，明确说明哪些控件适用。
- 用稳定、唯一的模型颜色；拟合散点坐标范围，保留完整0–100%坐标和Base/RF局部视图。点不抖动、不移动、不改变面积或覆盖。
- 卡片显示命中计数、距目标绝对差、两种面积口径；默认参考统一为F2 Base。小改善如实呈现，完整方法和区间保留。

独立脚本未导入生产的分数/面积/汇总函数。复核45000个可评分区域的球面对数、分数及覆盖；主截图1014个区域（6个方法×169终点）的球面面积和匹配面积比；338808次历史标签成熟条件。最大分数差6.14e−12，最大面积相对误差2.00e−15。验证前后源文件SHA-256相同。

该审计没有重新训练/冷启动全部模型，也没有从零重放所有预热秩阈值；它不能被称为“整条科研链路无任何问题”的证明。对应模型冷启动与输入审计另见 `DIRECT_FEEDBACK_AUDIT_CN.md`。
