# 真实TabPFN实时推理与残差校正

实时预测需要推理服务，网页刷新只读取已发布结果。

当前私有算法：每次新的UCAR 6h观测网格到达后，原冻结TabPFN CV-F2计算运动偏差预测；C0读取原特征和Base，C1另读取同场同lead、valid time不晚于当前起报的成熟残差及年龄/缺失标记。历史残差经平行移动统一坐标，随后按原规则校准位置区域。没有将后来真值写回更早起报。

`cyclone_tfm_live.inference_bridge`只连接这个已验证私有执行器，不分发权重、训练/校准原始数组或完整算法。发布前检查Base/C0/C1同起报、来源摘要、时距/有效时间、坐标范围和原始生成时间；不从旧缓存造出“新预测”。

## 当前Mac可执行的两种模式

已有私有`refresh_champi_operations.py --watch`运行时，桥接器只观察它的真实输出，不重复启动推理：

```bash
PYTHONPATH=src /path/to/scientific-python -m cyclone_tfm_live.inference_bridge watch \
  --research-root /path/to/private-research \
  --python /path/to/scientific-python
```

若由桥接器单独负责推理，则增加`--run-inference`；不要同时运行另一套旧更新器。每次执行完成后才等待下一轮，单实例文件锁阻止桥接器自身重叠。电脑休眠/关机将停止本机推理。

默认只生成校验后的待发布文件，**不上传**。只有单独配置该公开仓库的发布凭据并显式增加`--publish`后，才通过普通非强制Git推送写入`live-data`；原始模型时间不改写。不得把密钥、权重或私有研究目录提交到仓库。凭据未配置时应保留未发布状态，而不是宣称公网模型实时更新。

GitHub云端按计划检查官方资料与外部路径并部署网页。模型转入`live-data`后，下次云端部署才出现在公网；30分钟计划任务可能延迟，并不承诺秒级更新。网页上只有官方资料更新而模型未更新时，各自时刻分别显示。

## 展示与验证边界

Base/C0/C1的点误差、联合覆盖及区域效率须分别评价；C1/C0隔离残差历史的增量。已成熟标签回放使用修订资料，不能推断历史真实公开时延。地图当前实时区域是该版本缓存实际给出的圆；历史椭圆与实时圆不混算。
