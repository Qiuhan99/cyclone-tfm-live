## 固定F2输入与上下文

每次使用最近9个连续6h定位点，覆盖48h。F0共21维：纬度9、相对经度9、经度sin/cos2、时效1；F1共40维：增加6/12/24/48h运动、速度航向、加速度、转向与曲率、尺度运动差；F2共52维：另加风速／气压及24h变化、缺失标记、年内日期sin/cos和训练期气候运动。缺测数值置0并附可用标记，0不代表实际零强度。

气候运动是截至2015年历史资料的32近邻加权运动，不是官方CLIPER。固定1020条历史上下文按五时效分层各204条，涉及761场风暴，选中上下文时间范围1945–2015；不是1020条CHAMPI观测。2016年最近320条已完成样本拟合二层校正，2017验证集选定CV-F2，2019预热Conformal。CHAMPI不用于重新选择特征组或权重。版本为本地TabPFN-3.5冻结检查点，CPU、1估计器、随机种子42、中位数输出。

这是预训练基础模型的历史上下文推理，没有在CHAMPI上做梯度微调；仍依赖带标签历史上下文及Conformal分数，不能称为完全无历史标签、无校准数据。

## 位置推理与残差

以起报位置p_t为球面切平面锚点。先将最近6h运动作等速度球面外推，得到d_CV。基础模型学习历史真实位移Log_p(Y)减d_CV的偏差：

    d_Base(t,h) = d_CV(t,h) + f_F2(X_t,h)
    r(t,h) = Log_p_t(Y_t+h) - d_Base(t,h)
    d_C1(t,h) = d_Base(t,h) + g(X_t,h, d_Base(t,h), R_past)
    predicted_position = Exp_p_t(d)

h为6/12/24/48/72h。C0是52维F2加2维Base，共54维；C1再加4条同场同lead成熟残差，每条含东／北、年龄/144和可用标记，共70维。历史残差通过大圆平行移动对齐当前起报切平面；只用过去起报、valid_time≤当前issue、成熟年龄≤96h的最近四条；不足补0并附标记。

二层上下文仍固定2016样本。新CHAMPI成熟残差更新输入和校准，不等于重新拟合C1历史上下文。当前没有F3环境引导气流、ERA5或NWP特征，也未启用Regime Gate；校正全量加回，C1/C0用于隔离残差信息增量。各方法改善与退化均保留，未改写旧实验。

## Conformal与科学边界

每个模型使用2019预热分数，滚动取最近100条成熟分数，秩为ceil((n+1)(1−α))，分别输出80/90/95%。24h边际等待24h标签成熟；五时效标准化最大误差MaxScore联合事件等待整条72h路径成熟，尺度固定取2016平均误差。两者不能混称24h联合覆盖。

实时位置集合沿用实际模型版本的球面圆；原历史研究中的椭圆仍独立呈现，没有将它补画为新实时预测。Conformal不强制圆形，但上线椭圆需要独立成熟几何、分数和版本验证。时间依赖、漂移及历史单行原始发布时间未知时，只报告经验校准，不宣称无条件有限样本覆盖保证。当前下载资料可用于之后的新预测；用修订资料重建过去残差，不等于证明历史实时可用。

TabPFN只预测中心位置。未来风速来自实际外部模式字段；官方风级与预警来自中央气象台。登陆候选为自然地理海岸与中心线的几何交点估计，不是登陆概率或官方登陆判定。

## 当前Mac自动运行与网站同步

登录后由一个LaunchAgent运行桥接器：检查公开源→调用既有私有预测器→校验Base/C0/C1→普通非强制推送两个公开JSON到live-data。最小检查间隔900秒，上一轮完成后等待下一轮，文件锁阻止同一桥接器重叠。相同B-deck字节内容和预测器版本复用原模型生成时间；新定位或修订内容才重算。公开核验时间、模型起报和模型生成分别记录。

live-data更新由SSH部署密钥推送，触发Pages构建，始终从main读取网站代码；公开源仍有每小时第7/37分钟的云检查。云构建保存数据前合并较新的模型，Mac上传合并较新的官方资料，非强制推送处理并发。前端每60秒检查JSON，端到端延迟另含推理、网络、Actions排队和部署时间。上传成功与网站已部署分别核验，不承诺秒级更新。

Mac睡眠、关机、退出登录或断网会停止／延迟本地更新；公网仍保留上次成功版本并按时间提示过期。后台任务不修改系统睡眠设置。关闭部署密钥可撤销上传权限；原模型和样本继续本地保存。当前只适配CHAMPI，不能改名冒充任意活跃台风支持。
