# TabPFN-TS × 因果残差反馈 × 同校准层：首轮对照

研究主线已恢复为通用TFM本身的预测与Conformal；本实验不把权威气象预报改作主Base，不引入GRIB，不以MAE门控删掉残差预测。全部本机离线。

## 实际执行与任务边界

历史8场长寿命风暴沿用原协议的48个真实模型缓存（6个k），核对哈希并重新运行原PI+阈值；新增固定阈值对照。2017–2019的3场列为验证，2020–2023的5场/60个目标列为历史测试。均已在前期研究查看，属于探索性。没有按本轮效果筛选风暴或k。

CHAMPI原始39个连续6h中心：重新运行官方TS基线及原C0/C1，全部k=1/2/4/8/16/32；另单独运行31个固定起报、每次12步的官方TS路径，保留155条6/12/24/48/72h预测，其中128条可评分、27条未来无真值。历史缓存复用与CHAMPI新推理明确区分。

在线试验的覆盖事件是下一6h中心的纬经两个坐标同时覆盖，不是单次起报整条6–72h轨迹的联合覆盖。C0/C1每6h收到新观测后发布；陈旧Base只在块首发布。主要结果预定k=1，其他k为敏感性诊断，不能将逐步更新的C1拼成块首已经发布的路径。

固定阈值下C1覆盖没有改善、匹配面积比反而大于1；因此本轮信号依赖校准配置，不能称所有CP方法都受益。

原生分坐标95%矩形，以Bonferroni解释为目标90%的二维覆盖，k1在9个评价点实际覆盖66.67%。它未经Conformal校准，不构成分布无关保证。原生矩形和椭圆形状不同，不直接把两者面积差归因于残差学习。

CHAMPI校准窗只有9个分数，校正器首轮只有7个训练样本；原PI+在此短窗未稳健校准。其C1+PI+实际覆盖55.56%，固定阈值66.67%。后验90%目标排序在9点只能达到100%覆盖，故表中匹配面积也不是已实现的名义90%区域。单场不做风暴级显著性声明。
