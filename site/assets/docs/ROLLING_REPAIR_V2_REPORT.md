# 滚动四残差二层 TabPFN v2：本地实验与网站更新

日期：2026-10-21。状态：**已完成真实本地推理；探索性，未显示C1区域效率优势**。

## 1. 回答本次研究问题

v2补齐了v1缺少的显式基础预测、四个已验证残差、滚动模型上下文与动态几何/分数校准。**修复和扩展之后，当前台风应用仍不支持“C1在相同覆盖下区域更紧致”**。Base固定CP的欠覆盖可被动态CP缓解，但该收益不能归给C1。没有依据将整个主研究推翻，也没有依据从ECL/合成正结果直接推定台风必然成功。

v1负结果、λ=0部署门控及旧索引审计完整保留。v2预先固定原始λ=1，将残差增量作为研究对象；**本轮未新增验证集选择的收缩/门控部署策略**，也没有按测试表现调整λ或时效。2017验证独立报告，2020–2024已暴露历史测试，均标为探索性。

## 2. 锁定的预测协议

- 复用v1安全Base及同一114风暴/1,245起报点；基础模型训练标签早于2016，使用最新三个连续历史位置。研究窗口6/12/24h；内部预测6/12/18/24h四步。保留原H=72h可用队列，不把它称作所有24h可用起报点。
- C0为完整原始X10维＋当前Base东/北位移2维；C1再加四个不同历史起报点的同风暴同h残差ENU、年龄和可用标记，总28维。只取已验证标签，年龄≤96h；缺失填0并置mask=0。年龄数值为六小时步数/24。历史ENU在原预测端点的东/北基底表达，未作平行移动。
- 以跨风暴样本池训练，每h/ENU分别拟合实际TabPFN-3.5。最新320条已到达训练对，每32条新标签后刷新。目标为Base样本外残差。输入是各训练对**原起报时**的特征，不能用训练时已揭示的新信息重建旧输入。最初32个完整标签前回退Base。
- 1 estimator、seed42、CPU六线程、预测中位数、本地固定checkpoint；C0/C1共享上下文和刷新时点；同信息集滚动Ridge作对照。共4时效×74刷新组×2 TabPFN臂×2分量=1,184组件组，缓存记录各组上下文/查询索引及输入哈希。
- 同一冻结上下文的查询按组计算，每条查询保留自己的因果特征。其他查询扰动和单查询数值敏感度另作审计；不把数值检查当作统计有效性证明。

## 3. 同规则动态联合区域

对方法m、起报t、前缀H，用已完成的最近128条创新拟合几何：

Σ或Ω的样本协方差 → 0.1单位阵收缩 → 正特征值地板。

分数为MaxScore `max(h≤H) sqrt(U_hᵀ Σ_h⁻¹ U_h)`，或完整Mahalanobis `sqrt(Uᵀ Ω⁻¹ U)`，其中U在各方法预测端点重新锚定。

历史起报s的分数始终使用**s起报时冻结的几何**。只有s+6H小时完整标签到达后，才将该分数放入校准队列。起报t以最近256个已完成分数的 `k=ceil((n+1)(1−α))` 秩确定阈值，至少100分数。等起报时刻共享同一历史，标签到达按时间排序；不按风暴循环提前读入后发生的风暴。

Base、C0、C1、Ridge均用同一规则。另提供Base和滚动C1的固定2018几何/2019校准参考。动态方案是延迟滚动秩，**未实现PI+反馈控制器或QRF，不称为ECL完整复制**。非交换、漂移条件下只报告历史经验覆盖，不声称标准split conformal的有限样本保证。

对2H维集合：MaxScore产品椭圆的logV为 `H logπ + 2H logq + ½Σ logdetΣ_h`；全维椭球为 `H logπ − logΓ(H+1) + 2H logq + ½logdetΩ`。所有形状和阈值随起报变化，因此报告平均logV。它不是球面内禀面积，亦不是各步包络半径。

后验匹配使用测试比值 `S_i/q_i` 的经验秩作单一全局尺度c，使每个方法均达 `ceil((1−α)N)/N` 经验覆盖；平均logV增加 `2H logc`。这是**等经验覆盖的探索性诊断**，c永远不用于地图。体积比 `exp(mean(logV_C1)−mean(logV_Base))` 是几何平均体积比。500次配对整风暴bootstrap在每次重采样内重估c；非确认性区间，未建模跨风暴依赖与漂移。

## 4. 测试结果：名义90%、MaxScore

|时效|Base固定CP覆盖|Base动态CP覆盖|C1动态CP覆盖|等覆盖C1/Base几何平均体积比|匹配ΔlogV的95%区间|
|---|---:|---:|---:|---:|---:|
|6h|88.27%|90.12%|90.04%|1.006×|[-0.070, 0.097]|
|12h|86.99%|89.80%|89.64%|1.046×|[-0.073, 0.230]|
|24h|87.47%|89.72%|89.08%|1.401×|[-0.045, 0.667]|

三种方法的后验匹配覆盖均为90.0402%。24h的C1点估计体积增加约40.1%，区间跨零；不能描述为效率改善。完整Mahalanobis下24h C1/Base等覆盖体积比约2.102，ΔlogV区间[0.362,1.144]，在这一探索性重采样下支持退化。没有隐藏另一种分数的负结果。

24h相同动态CP下：C0覆盖89.80%、等覆盖体积比1.250；Ridge覆盖89.88%、体积比1.226。C1未显示超越无残差C0或同输入Ridge的稳定优势。固定参考可能在后验等覆盖下比滚动几何更小；因此也不能把“动态CP”直接等同于“同覆盖更有效率”。

辅助点误差MAE(km)：6h Base37.27 / C137.56；12h78.63 /79.51；24h184.60 /198.44。24h等速度210.25、Persistence439.59。完整管线仍优于这两个便宜基线的该项总体误差，但C1增量不优于Base；网站同时呈现这两层比较。
